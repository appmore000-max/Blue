# 藍天白雲傳承

## 而這是一個專案，不是三個 demo

---

# 怎麼跑

**這個專案用 ES 模組，所以要本機伺服器，不能直接雙擊 index.html。**

```bash
cd app
python3 -m http.server 8000
```

**然後開 http://localhost:8000**

---

## 而如果直接點開 index.html

**畫面會告訴你要用伺服器。而它不會白畫面。**

# 三個模式

| | 資料來源 | 狀態 |
|---|---|---|
| **那些事** | `script/` 全部 125 篇 | 可讀。有進度、逐字、自動、長按跳過 |
| **對練** | `characters/` + `world/chronology.json` | 可推演。**四個條件選擇器＋年份** |
| **那一天** | `world/event_grading.json` | 可玩。七個結局 |

---

## 而「那些事」的六種框

| t | 畫面上 |
|---|---|
| `narration` | 沒有名牌 |
| `emphasis` | **逐字慢 30%，自動多停 0.4 秒。不換顏色，換字重** |
| `speech` | 有名牌。**而名牌跟視角走** |
| `quote` | 框內框。不逐字 |
| `screen` | 手機／群組畫面 |
| `section` | 小字，淡入淡出。**不需要點** |

---

## 而 `pause_before` 是節奏

**它是那一框前面有幾個空的 `---`。**

**而小說裡的空白，在畫面上是時間。**

| 0 | 直接接 |
| 1 | 停 0.3 秒 |
| 2 | 停 0.6 秒 |
| 3+ | 停 1 秒。而那通常是換場 |

# 測試

```bash
npm install       # 只有 jsdom，一個
npm test          # 契約 + 整合
```

| | 做什麼 |
|---|---|
| `test/contract.mjs` | **資料契約**。程式讀的每一個欄位，拿去對真的資料 |
| `test/spec.mjs` | **設計對實作**。設計文件裡的每一條規格，拿去對程式碼 |
| `test/smoke.mjs` | **整合**。把六個模式真的掛起來、真的渲染、真的點 |

**12 + 35 + 28 項。而它們不是檢查檔案在不在。**

## 而 `spec.mjs` 是為了不要靠記憶

**「還剩什麼沒做」這個問題，應該由文件回答。**

**而它抓到過一項：**

> **「不對等」資訊模式 —— 設計裡最重的一條，而它沒有做。**

---

## 而它抓到了三個 bug

**一｜中文 hash 沒 decode。**

點任何一篇都會靜靜地退回目次。**而它不報錯。**

---

**二｜框型對照表對不上。**

劇本檔裡的 `t` 是全名（`"speech"`），而程式碼的表用縮寫（`"s"`）。

**所以 `type` 是 undefined ——**

**逐字、強調、引用、名牌，六種框全部失效。**

**而畫面看起來還是有字。**

---

**三｜停頓期間的連點會把整框吃掉。**

而那一框的字一個都沒有出現過。

---

## 而三個都是「看起來正常」的

**這正是這個專案第四次遇到同一件事。**

---

# 而契約檢查是為了不要有第五次

**因為那個 type 的 bug，本質是「程式以為的資料形狀」跟「資料實際的形狀」對不上。**

**而那一類問題不會報錯。**

---

## 而它抓到的第二件事

**五種招式消耗沒有對照到，而它們全部被當成預設值 12。**

| 招 | 消耗 | 而資料裡寫的 |
|---|---|---|
| 強葬·爆發 | `LIFE` | **燃燒氣血與壽命。而那不是存，也不是本** |
| 阿智·解禁自身 | `BEN` | **扣的是本。而且不是他啟動的** |
| 吳紫儀·解放 | `double` | 氣量耗盡即強制解除 |
| 林若霜·緊急外科 | `0` | **這一項不是能力。是醫學系七年＋急診科** |
| 華邦·瞬間移動 | `very_high` | 而這一項扣得最兇 |

**而全部當成 12，等於把設定拆掉。**

**已補齊。而其中四項不會被隨機挑到——因為它們不是那種招。**
